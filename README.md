# Pásala

Juego de fiesta en español para adivinar frases. Se juega **con el teléfono
acostado**, pasándolo de mano en mano: describes la frase sin decirla, tu
equipo adivina, y pierde el punto quien lo traiga cuando suene la chicharra.

**Para jugar: https://rone791.github.io/pasala-web/**

Está en pruebas con familia y amigos. Si algo no funciona o alguna frase no se
puede describir, avísale a quien te pasó la liga.

---

Este repositorio contiene únicamente la aplicación ya compilada, publicada para
que se pueda jugar desde un navegador. El código fuente es privado.
